📺 StreamBox on your TV

Get the app on Android TV / Fire TV and drive it with your remote.

1 · Install the APK (one time)

  1. On GitHub, open Actions → Build StreamBox APK → download the streambox-apk file and unzip it — pick full (all animations) or lite (calm, max smoothness). Easier: grab them at Releases → latest.
  2. Send the APK to your TV: use the Send Files to TV app (phone + TV), a USB stick, or the Downloader app.
  3. On the TV, open the file with a file manager and choose Install. If asked, allow Install unknown apps for that app (Settings → Apps → Special access).
  4. Find StreamBox in your app list / Leanback launcher and open it.

2 · Remote controls

  • ⬅️ ➡️ ⬆️ ⬇️ — move between posters, buttons and episodes
  • ✅ OK — open details / press ▶ Watch Now / start an episode
  • 🔙 Back — close popup → straight home → exit app
  • On a movie popup, focus starts on ▶ Watch Now — one OK press plays.
  • Change season/episode with the ‹ › steppers, never a dropdown.

3 · Smooth-playback tips

  • 📶 Use 5 GHz Wi-Fi or Ethernet — 2.4 GHz stutters on HD streams.
  • 🛡️ Keep Ad Shield ON (blocks popup ads and tab hijacks).
  • ↻ If a video stalls, press Reload under the player, or try another episode/server.
  • ⇄ Wrong film playing? Some free servers mislabel titles — press ⇄ Source under the player to switch to another source. Right title, wrong cut (remake plays the original)? Press 🎬 Wrong version? to jump to the next mirror.
  • 🖥️ Edges cut off in fullscreen? Set your TV Picture mode to Just Scan / Screen Fit / 16:9 (not Zoom) — TVs crop the picture by default (overscan).
  • 🔌 Close other apps on cheap TV sticks to free RAM.

4 · Phone & tablet

Open the website in Chrome/Safari → menu → Add to Home Screen / Install. No APK needed.

Troubleshooting

  • Site looks old after an update? — hard-refresh once (browser) or clear the app's data (TV app). Updates then arrive automatically.
  • New APK looks identical? — the app auto-wipes its cache on the first launch of each new version. If it still looks old, uninstall first, then install the new APK.
  • App not in launcher? — check Settings → Apps → StreamBox, or reboot the TV.
  • Can't press Install? — enable “Install unknown apps” for your file manager first.
  • Black player? — press Reload; if it persists the stream server is down, try later.
  • Remote does nothing? — press any arrow once to wake focus, then navigate.
